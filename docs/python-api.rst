Python API
==========

The ``vehicle_lang`` Python package exposes the same functionality as the ``vehicle`` CLI together with helpers for embedding specifications directly into your training code. This page summarises the supported entry points and links to the autogenerated API reference for each module.

Installation
------------

Install the base package from PyPI:

.. code-block:: bash

  pip install vehicle_lang

Loss backends live behind optional extras so you only pull in the deep-learning frameworks you need:

.. code-block:: bash

  pip install "vehicle_lang[pytorch]"
  pip install "vehicle_lang[tensorflow]"

Loss compilation
----------------

Use the backend-specific ``load_specification`` helpers to compile a ``.vcl`` specification into Python callables. Each property in the file becomes an entry in the returned dictionary and expects the ``@network`` functions referenced inside the property:

.. code-block:: python

  import vehicle_lang as vcl
  from vehicle_lang.loss import pytorch as loss_pt

  declarations = loss_pt.load_specification(
     "spec.vcl",
     logic=vcl.DifferentiableLogic.Vehicle,
     declarations=["output_bounded"],
  )

  constraint_loss = declarations["output_bounded"]

  def network(x):
     return model(x.reshape(1, 1)).reshape(1)

  total_loss = task_loss + 0.5 * constraint_loss(network)

Custom samplers can be supplied through the ``samplers`` argument, and any pre-defined objects (e.g. models, datasets, configuration) can be passed via ``declaration_context``.

Logic selection
---------------

The differentiable backend is controlled through ``vehicle_lang.DifferentiableLogic``. ``DifferentiableLogic.DL2`` remains the default, while ``DifferentiableLogic.Vehicle`` enables the experimental in-Vehicle optimisation pipeline.

Exceptions
----------

All public functions raise ``VehicleError`` (or one of its subclasses) whenever the underlying CLI reports a failure. Catching these exceptions gives you access to the stderr emitted by the executable.
